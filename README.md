# 🛒 বাজার দর | BazarDor

BazarDor (বাজার দর) is a Bangla-based market price tracking web application that helps users explore daily product prices, compare prices across different markets, and stay informed about market price changes.

## 🛠️ Technologies Used

- **Next.js** – React framework for building the application
- **React** – Component-based user interface
- **TypeScript** – Type-safe development
- **Tailwind CSS** – Utility-first styling
- **DaisyUI** – Ready-made UI components
- **HeroUI** – UI component library
- **Better Auth** – User authentication
- **Lucide React** – Icons

## ✨ Key Features

1. **Product Browsing** – Browse a collection of daily essential products with their latest prices.
2. **Category-Based Filtering** – Explore products by category and quickly find the items you need.
3. **Market Price Comparison** – Compare product prices across different markets and view minimum, maximum, and average prices.
4. **Price Change Tracking** – See whether product prices have increased, decreased, or remained unchanged.
5. **Scrolling Price Ticker** – Stay updated with product prices and market changes through an animated horizontal ticker.
